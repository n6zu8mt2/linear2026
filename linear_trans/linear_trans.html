線形変換とは 📐

2次元ベクトル $\boldsymbol{x} = \begin{pmatrix} x \\ y \end{pmatrix}$ は、基本ベクトル $\boldsymbol{e}_1 = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ と $\boldsymbol{e}_2 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$ を用いて次のように分解できます。

$$ \boldsymbol{x} = \begin{pmatrix} x \\ y \end{pmatrix} = x \begin{pmatrix} 1 \\ 0 \end{pmatrix} + y \begin{pmatrix} 0 \\ 1 \end{pmatrix} = x \boldsymbol{e}_1 + y \boldsymbol{e}_2 $$

これのことから、$\boldsymbol{x} = \begin{pmatrix} x \\ y \end{pmatrix}$ を次のように解釈できます。

  • $\boldsymbol{e}_1$ 方向（$x$軸方向）に $x$ だけ進み、
  • $\boldsymbol{e}_2$ 方向（$y$軸方向）に $y$ だけ進む

ことで得られる位置ベクトルが $\boldsymbol{x}$ です。

この$\boldsymbol{x} = \begin{pmatrix} x \\ y \end{pmatrix}$ に、行列 $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$ による線形変換を施すと、変換後のベクトル $\boldsymbol{x}^\prime$ は次のようになります。

$$ \boldsymbol{x}^\prime = A \boldsymbol{x} = A (x \boldsymbol{e}_1 + y \boldsymbol{e}_2) = x (A \boldsymbol{e}_1) + y (A \boldsymbol{e}_2) $$

これは、変換後の世界でも同様に考えることができることを示しています。つまり、変換後のベクトル $\boldsymbol{x}^\prime$ は、

  • $\boldsymbol{e}_1$の変換後のベクトルである $A\boldsymbol{e}_1 = \begin{pmatrix} a \\ c \end{pmatrix}$ 方向に $x$ だけ進み、
  • $\boldsymbol{e}_2$の変換後のベクトルである $A\boldsymbol{e}_2 = \begin{pmatrix} b \\ d \end{pmatrix}$ 方向に $y$ だけ進む

ことで得られるベクトルとなります。つまり、変換後の世界では、基底ベクトル $\boldsymbol{e}_1$ と $\boldsymbol{e}_2$ が、 $A\boldsymbol{e}_1$ と $A\boldsymbol{e}_2$ に変化し、空間全体（格子）がそれに合わせて歪みます。
